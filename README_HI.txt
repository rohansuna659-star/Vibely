VIBELY — Android starter project

Is project mein:
- White + Blue Instagram-style demo UI
- Stories row aur sample feed posts
- Like button toggle
- Explore/Create/Activity/Profile ke demo buttons

Zaroori baat:
Yeh abhi FRONT-END DEMO hai. Login/signup, real photo/video upload, server, chat,
notifications aur real users abhi connected nahi hain. Is ZIP mein ready APK nahi hai.

APK banane ka tarika:
1. Computer par Android Studio install karein.
2. Is ZIP ko extract karein.
3. Android Studio mein extracted VibelyAndroidProject folder open karein.
4. Gradle sync complete hone dein.
5. Build > Build Bundle(s) / APK(s) > Build APK(s) select karein.
6. APK app/build/outputs/apk/debug/ mein milega.

Build ke liye Android Studio/Gradle setup aur internet ki zaroorat ho sakti hai.
